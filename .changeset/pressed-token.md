- Added: a `pressed` color token (zinc-300 light, zinc-600 dark) for the fill while a row, tab, day or page button is held down, one step past its hover. `text` keeps 7:1 or better on it. Components start using it in the following changes.
- Docs: a States section in the foundations that sets one state model (rest, hover, pressed, focus, selected, disabled, invalid) with the tokens for each.
