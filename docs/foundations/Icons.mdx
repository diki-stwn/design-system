## Gallery

The everyday icons, grouped by use: these work by name with `<Icon name="…" />` and the components' `icon` props. For anything else, find it in [the full set](https://fonts.google.com/icons?icon.style=Rounded&icon.set=Material+Symbols) and import it: `import { RocketLaunch } from "serupa-ds/icons"`, then `icon={RocketLaunch}`. To add an everyday icon, add its name to `docs/icon-names.json` and run `python3 tools/icons/material.py`. Your custom icons appear at the end once you add some.
